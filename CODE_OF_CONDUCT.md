# Code of conduct

## The short version

Argue with the claim, not with the person who made it. This project exists to
make disagreement productive, and that only works if disagreeing is safe.

## What we expect

- Assume the other person read the documentation and still disagrees. Usually
  they did.
- Say what you would change and why. "This is wrong" is not a review.
- Accept that a rule you dislike may be correctly classified. `opinion` is a
  valid basis, and so is disagreeing with one.
- When you are wrong, say so plainly and move on. Nobody keeps score here.

## What we will not accept

Harassment, personal attacks, discrimination on any ground, publishing
somebody's private information, or sustained disruption of a discussion.

Tenant data belonging to somebody else does not go in an issue, a pull
request, or a comment. If you need to show a report, fabricate the numbers, as
the fixtures in this repository do.

## Scope

Issues, pull requests, discussions, and any space where somebody is
representing this project.

## Enforcement

Report to **support@ph7x.com**. Reports are handled privately.

Depending on what happened, the response ranges from a private note to a
permanent ban. We will say which, and why, to the person concerned.

The maintainers apply this to themselves first. If a maintainer breaks it,
report it the same way.
