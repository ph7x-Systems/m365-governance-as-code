# Reviewer packet

A frozen copy. **Do not edit, and do not regenerate from `rules/`.**

Two reviewers, independently, receive exactly the three files in this
directory and nothing else:

- `SPO-LIST-001.yaml`
- `SPO-SITE-001.yaml`
- `BASIS.md`

No architecture, no trust model, no explanation of the engine, and no
description of this project.

They answer the questions in [../RULE-REVIEW.md](../RULE-REVIEW.md), in
writing, separately.

---

## Why this is a copy and not the rules themselves

The rules in `rules/sharepoint/` are executed by the engine and keep changing
as the product is built. The reviewer packet must not: a review is only
comparable to another review if both read the same text.

These files are the versions as they stood when the review was commissioned,
on 2026-08-05. The versions in `rules/` have moved since, and the differences
between the two are part of what the review is meant to inform.

A reviewer who is handed a newer file is answering a different question.
